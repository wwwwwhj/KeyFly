# 社区提审说明

## 应用资料

名称：键走如飞（KeyFly）
应用 ID：01a1afee-b107-7509-aca8-736dfe02f6cc
版本：0.1.0
简介：英文打字练习，单行题面逐字居中滚动，跟手的键盘反馈，随速度升级的光波与粒子动效。支持计时挑战、个人排行与练习记录弹窗。
图标：docs/icon.png（512 × 512），同目录 SVG 为原创源文件。

## 包与权限

上传 dist/package/app.zip。由官方 @discourse-mini-app/sdk/pack 生成，不含秘密凭据，不请求业务网络，不使用远程素材。

| 权限 | 用途 |
| --- | --- |
| user.read | 自动显示当前登录用户名称、头像，并按用户 ID 隔离本地成绩 |
| theme.read | 跟随社区深浅主题与减少动态效果偏好 |
| storage.read | 恢复当前浏览器的个人练习记录 |
| storage.write | 保存最近 20 条记录，每条存储值保持在 4 KiB 限额内 |

没有额外账号系统。SDK 拒绝存储时显示提示，当前练习仍可继续。保存内容只有时间、语言、设定时长、用时、速度和准确率，不保存练习输入全文、头像 Blob URL 或认证令牌。无跨用户排行榜，无实时通信。文字为原创，图形为代码绘制，没有外部字体或音频。

## 沙箱验收

1. 在应用管理的沙箱页上传并保存 app.zip；等待构建处理成功，再进入该构建对应的 sandbox。
2. 确认首屏可用，右上角显示当前社区用户名与头像；无登录资料时显示访客，无另行登录表单。
3. 英文输入：正确键绿色反馈，错键红色，退格可改；下一键和大写字母的对侧 Shift 有提示。重复字符中间插入及同值替换的亮键与准确率应一致，输入法取消不计尝试；长按不会额外刷键盘热度。
4. 逐渐加速：键盘从准备到节奏、疾速、超频，出现扩散光波、粒子拖尾和跨键流光；停止后衰减。关闭速度特效或启用减少动态效果后，不应继续出现粒子运动。
5. 检查单行题面：未输入文字浅色，正确输入后加深；输入、退格、方向键及选区替换时，真实光标、当前词释义和下一键同步，缩放仍居中。Home/End 对应全文首尾，满长度插入不截掉未选中的尾部。时长使用分段按钮，重来图标可重置练习。显示选项和说明折叠在键盘下方。
6. 完成一次全文与一次计时练习，检查速度/准确率/排行分组与记录恢复；切换账号后不显示前一个账号的记录。
7. 练习中打开排行、记录弹窗或切到后台：暂停并保留内容；弹窗支持 Esc、焦点约束与关闭后恢复焦点，手动继续后恢复计时。到时输入被锁定，不能修改最终成绩。
8. 验证桌面 1280×720、1440×900 和 1920×1080、深浅主题、键盘焦点、减少动态效果、存储拒绝与重新打开。
9. 沙箱确认后按社区流程选择构建、填写更新说明并提审；新正式发布版本应递增。

本地已验证核心规则、浏览器交互和生产包 SDK 模拟接口；真实社区加载器、权限审批与登录资料仍需要上述沙箱验收。
