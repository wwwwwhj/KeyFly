# 练习工作台

Mode: Operate。用户明确选择宽题面的专注练习；后续明确键盘反馈为最重要功能。

## Direction contract
THESIS: 正确、跟手的输入反馈是主体，击键速度驱动动态体验。
OWN-WORLD: 低干扰绿色工作台与深色实体键盘，题面由浅色变为正文深色，键盘绿色正确、红色错误，青/金色只表示速度热度。
STORY: 切换练习时长，直接输入英文题面，当前字符始终居中，看到按键回弹与热度升级，完成后通过弹窗查看个人成绩。
FIRST VIEWPORT: 右上角显示社区用户名与头像，时长分段按钮和重来图标紧凑排列；单行题面与输入合一，键盘在下，不保留顶部 tab。排行与记录通过弹窗展示，打开时暂停并保留进度。
FOCUS: 主视野保留文字、释义与键盘反馈；显示设置和操作说明折叠在键盘下方，删除速度宣传文案、重复图例与页脚标语。当前词释义加深，光标跟随原生选区；1280×720 桌面保留完整键盘。
FORM: 用户指定的专注工作台与速度键盘体验；seed:6676410445f2dc98 仅为探索记录，最终范围以用户后续指示为准。
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

限制：不提供多人通信；共享社区榜尚未接入。没有营销图片或生成式素材；docs/icon.png 从同目录原创 icon.svg 转换，不随运行包加载。
